# cumpre.pt

Página de apresentação da Cumpre para estudantes. A app está em app.cumpre.pt (repositório cumpre-app).

- `site/` — o que o Netlify publica.
- `site/_redirects` — as páginas antigas (negócios) vão para o início.

Cada alteração enviada para o ramo `main` vai para o ar sozinha no Netlify.
